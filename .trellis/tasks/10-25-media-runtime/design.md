# 实现方案

共享FAT服务，原图片与RV16解析器使用外部文件服务接口；保留参数默认兼容单模块测试。切换先hold新帧，当前源帧/缩放/转场收尾；VS黑场确认后阻止新A/B读命令，等待已接纳读和全部写完成，再同时复位媒体两端FIFO及toggle链。SDRAM硬核、PLL、HDMI时序、菜单、应急与WAV不复位。WAV继续后台读取，视频模式屏蔽节目PCM（应急警笛保持），返回图片恢复WAV；不声称视频配音。

菜单保留六张主卡；长KEY3在节目/外设/媒体页循环，二级返回语义保持。媒体页模式卡进入编辑，KEY2图片/KEY3视频/KEY4确认；播放卡暂停继续在VS应用。少量英文卡标题复用ASCII ROM，不扩中文字库。

风险：模式清理必须等真实pipeline静止，不能用固定延时掩盖在途传输。RAW错误时可能源writer不完整，只有禁止新源且全部实际突发静止才能清理；完整读返回后才复位FIFO。
