# 设计

按用户已批准方案执行。

| 模块 | 设计 |
|---|---|
| 时钟 | 50→27 MHz→74.25 MHz 像素与 371.25 MHz 串行；必须由本机 TD 官方 PLL 参数及实际构建验证 |
| 时序 | H=1280+110+40+220=1650，V=720+5+5+20=750，HDMI VIC=4 |
| 缓存 | RGB565 两像素/32位字；每页 460800 字，页基址 0、0x80000；取消源图 scaler 暂存链 |
| 写事务 | 复用源写 ACK 隔离及双完成门，解析成功和本事务写完均到达才发布；错误、迟到 ACK 不发布坏页 |
| 读路径 | 2048字 FIFO、128字突发；静态只读取当前页，转场提前预取另一页，按像素半字解包 |
| 转场 | alpha 每帧推进8，完整输出目标预取帧后释放旧页，不恢复横推或揭示模式 |
| 界面 | x≥11位、y≥10位；原生 32px 字模；波形 x128/w1024/y576/h96，时间右下 |
| 音频 | 真实74.25 MHz下48 kHz分数节拍，运行时间按时钟计秒 |
| 工程 | 保留现有 TD 入口，新增 PowerShell 原生回归/构建入口覆盖原有检查 |

失败反例：解析器报成功时，写 FIFO 仍有最后几个字在途；若立即换页，会读到不完整尾行。使用写请求 ACK 作为事务边界，独立锁存解析完成与 writer 完成，提交后等待视频释放，防止下一次装载覆盖仍显示中的页。

参考老师第八讲 loader/reader 的完整帧发布、读页所有权，以及第十讲双页混合。既有负 setup 单独记录，不可将其冒充720p物理验证。
