# 图片与无声视频融合版操作说明

本版上电仍是原图片/WAV系统；同一块开发板、同一份bit，可从HDMI-A切到无声视频，再返回图片。不需要换接两块显示屏，也不需要更换bit来切模式。

## 烧录与素材

- 融合版：`D:/FPGA/code/example/releases/20261025-media-runtime/av_media.bit`。以同目录`verification.json`和SHA256SUMS为发布依据。
- HDMI-A：1280×720控制台，640×360逻辑画布2倍铺满。HDMI-B：1280×720节目输出。
- TF沿用原FAT32卡；原BMP/WAV保留。卡根目录还需有`VIDEO.R16`，可使用独立视频实验已经上板验证的同一文件，不必再次转换。
- 素材副本：`D:/FPGA/code/example/releases/20261025-media-runtime/media/VIDEO.R16`。本轮没有自动写TF卡或烧录。
- MP4不能直接放卡播放，也不能仅改后缀；FPGA读取的是PC预转换的RV16帧流。

## 切到视频

1. 上电进入节目控制页。长按KEY3约1秒再松开，到外设页；再长按一次，到`MEDIA PLAYBACK`媒体页。
2. 默认选中左上`MODE`卡，按一下KEY4进入编辑。
3. 短按KEY3选`VIDEO`；再短按KEY4确认。等待`WAIT`结束。
4. HDMI-B开始循环视频；首帧装载与切换期间可短暂黑场。图片、标题、时间、字幕及色彩设置继续由原控制页管理；原“图片”卡控制的是节目底图，关闭时也会遮住视频。

## 暂停、继续与返回图片

| 操作 | 结果 |
|---|---|
| 媒体页短按KEY2 / KEY3 | 上一张 / 下一张卡 |
| 选中右上`PLAYBACK`，短按KEY4 | 视频暂停 / 继续；`PAUSED` / `PLAYING`显示请求状态，实际在帧边界应用 |
| `MODE`编辑中短按KEY2 | 预选`PICTURE` |
| `MODE`编辑中短按KEY3 | 预选`VIDEO` |
| `MODE`编辑中短按KEY4 | 提交所选模式；不必先解除暂停 |
| `MODE`编辑中长按KEY2约1秒再松开 | 取消本次模式预选 |
| 未编辑时长按KEY2约1秒再松开 | 退出菜单，恢复播放按键 |
| 退出菜单后，视频模式短按KEY3 | 暂停 / 继续；KEY2不切图片 |
| 退出菜单后，图片模式短按KEY2 / KEY3 | 下一张图片 / 自动轮播开关 |
| 退出菜单后长按KEY3约1秒再松开 | 回到节目控制页 |
| 菜单顶层长按KEY3 | 节目→外设→媒体→节目，循环切页；二级页长按则返回节目页 |
| 任意页面长按KEY4约2秒 | 原应急开关保持有效 |

返回图片：媒体页选`MODE`→KEY4编辑→KEY2选`PICTURE`→KEY4确认。等待装载后恢复图片。原图片轮播状态在媒体链路复位时重新初始化，图片索引不是继续停留在切换前那一张；音量、图层、色彩等菜单配置保留。

`FORMAT`和`STATUS`是只读状态卡：图片显示`BMP`，视频显示`320X180 10`；切换中`WAIT`，正常`READY`，视频错误`ERRxx`。切换忙时不能重复提交模式。媒体四卡使用原ASCII字体，不占新增中文字库。

## 声音边界

图片模式保留原WAV和音量控制。切到视频后，WAV播放器继续后台读取，节目PCM输出静音，原应急警笛不被静音。返回图片时恢复WAV当前播放位置，不从曲首重新开始。

当前视频无音轨，没有视频音画同步；不能把后台WAV当作视频配音。暂停仅冻结视频换页，菜单、时钟、字幕、HDMI时序和应急功能继续运行。

## 错误与恢复

- 未找到R16、头格式或长度错误、短读、超时：不发布不完整画面。首帧前保持背景/黑场；已经显示过则保留最后完整视频帧。
- 媒体页会显示`ERRxx`。可按上述步骤返回图片，再切视频重试。无须把TF卡上原图片删除。
- `FORMAT`/状态显示的是FPGA内部请求与解析结果，不代表反馈检测了屏幕实际显示或扬声器发声。

## 上板检查

软件验证及物理实现结果见同目录`verification.json`；融合版仍需用户上板核验，独立视频版的板测通过不能替代融合版验收。

建议三分钟内依次展示：图片/WAV与音量→切视频→跨循环→暂停/继续→暂停状态返回图片→恢复WAV→应急进入/退出。确认双屏稳定、方向与颜色正确、无明显颗粒/撕裂；再检查原字幕和色彩控制仍有效。
