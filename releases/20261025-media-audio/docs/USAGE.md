# 图片与有声视频融合版

本版在原图片、WAV、双HDMI菜单和应急功能上加入视频原音轨。HDMI-A四卡标题改为中文：**模式、播放、格式、状态**。视频仍为离线转换的320×180、10帧/秒RGB565素材，4倍放大输出1280×720；不支持直接解码MP4。

## 配套文件

| 用途 | 文件 |
|---|---|
| 新烧录文件 | `D:/FPGA/code/example/releases/20261025-media-audio/av_media.bit` |
| 新有声视频 | `D:/FPGA/code/example/releases/20261025-media-audio/media/VIDEO.R16` |
| 实际验证与资源时序 | 发布目录的`verification.json`、`validation/`与`SHA256SUMS.txt` |

只有发布目录完整生成且`verification.json`的`passed`为true，才表示软件验收完成。`hardware_tested:false`表示本次尚未上板。

烧录新bit后，关机取下TF卡，备份卡上原`VIDEO.R16`，再把上表的新文件复制到**FAT32卡根目录**。BMP和WAV继续保留。旧RV16 v1文件兼容，但没有原音轨；只换bit、继续使用旧素材，视频仍然无声。本轮没有自动写TF卡、烧录或提交Git。

HDMI-A与HDMI-B仍接同一块板；HDMI-A控制台1280×720全幅，HDMI-B节目输出1280×720。屏幕扬声器需手动解除静音并设适中音量，FPGA音量功能才能听到变化。

## 切换和播放

1. 上电仍进入图片/WAV模式。菜单顶层长按KEY3约1秒再松开，在“节目↔媒体”两页间切换；设置二级页长按KEY3返回节目页。
2. 媒体页左上选“模式”，KEY4短按进入编辑。
3. KEY3短按选择`VIDEO`，KEY4短按确认。等待`WAIT`结束，开始有声视频循环。
4. 选中右上“播放”，KEY4短按暂停，再按继续。画面与原音轨一起暂停，HDMI时序继续。
5. 返回图片：选“模式”→KEY4编辑→KEY2选`PICTURE`→KEY4确认。暂停状态也可直接返回。

切换不再主动输出秒级黑场：装载期间保留上一张完整画面，新图片整页完成后才淡化切换。**仍有读卡/缩放等待时间**，这段时间看到的是视频最后一帧；上电尚无完整画面时仍可能显示背景。返回图片后从图片初始装载流程开始，WAV从头重启；音量、图层、色彩配置保留。

| 按键 | 作用 |
|---|---|
| 媒体页KEY2 / KEY3短按 | 上一张 / 下一张卡 |
| “模式”编辑中KEY2 / KEY3短按 | 选择图片 / 视频 |
| “模式”编辑中KEY4短按 | 确认模式 |
| “模式”编辑中KEY2长按约1秒 | 取消预选 |
| 未编辑时KEY2长按约1秒 | 退出菜单，恢复播放快捷键 |
| 退出菜单后KEY3短按 | 视频：暂停/继续；图片：自动轮播开关 |
| 退出菜单后KEY2短按 | 图片：下一张；视频：不切图片 |
| 退出菜单后KEY3长按约1秒 | 返回节目控制页 |
| 任意页面KEY4长按约2秒 | 原应急模式开关 |

“格式”和“状态”为只读卡。中文修改针对四卡标题，页名与部分状态缩写仍为英文。`WAIT`表示切换中，`ERRxx`表示解析/读卡等内部错误；它们不是屏幕或扬声器的物理反馈。

## 外设页已删除

按用户允许的资源取舍，删除整个外设检测页及蜂鸣器菜单测试。节目六卡、媒体四卡，以及屏幕、字幕、音频二级设置保留。真实板载LED仍沿用原指示逻辑，应急蜂鸣器不受影响。

## 音轨和异常

- 本片97帧、9.7秒；PCM48kHz、16bit小端、双声道，每视频帧4800个立体声样本。共享原扇区缓存与PCM FIFO。
- 正常按每6个60Hz帧换页；素材迟到时保持旧页，当前4800样本结束后输出静音等待，避免音轨持续跑到画面前面。实际流畅度仍需TF卡与板级验收。
- 暂停保留FIFO和音轨位置；循环不清FIFO，按尾部接首部播放。节目音量与静音作用于原音轨，应急警笛优先。
- 不完整视频页不会发布。视频音轨读错时显示错误并静音，画面可降级继续；返回图片再切视频可重试。
- 请勿热拔卡。文件必须由转换器生成，不能把MP4改后缀当RV16。

## 上板验收与回退

建议按顺序检查：图片/WAV→有声视频→跨一次循环→暂停/继续→暂停时返回图片→WAV从头恢复→音量/静音→应急进入/退出。观察双屏稳定、返回时保持末帧、无花屏，并听声音是否与原视频相符。

新bit的软件验证不能替代上板。稳定融合版保留于`releases/20261025-media-runtime/`，独立无声视频板测版保留于`releases/20261025-raw-video/`；回退时使用对应旧bit和原v1素材。
