## 本次变化

仅缩短视频返回图片后的首张淡化：32 个 VS 步进改为 8 个，60Hz 下动画减少约 0.4 秒。开机首张与普通切图仍为 32 步；没有跳过读卡、完整图片缩放、帧边界提交或双缓冲交接。

确认返回之后，仍须等待新图片完整装载；这段时间保持最后一张完整画面。因此本次不承诺消除全部 1–2 秒等待，也不把仿真时间当作真实 TF 卡时间。

## 操作不变

1. 菜单顶层长按 KEY3 约 1 秒，在“节目”和“媒体”页之间切换。
2. 媒体页选“模式”，短按 KEY4 编辑；KEY2 选 `PICTURE`，KEY3 选 `VIDEO`，短按 KEY4 确认。
3. 视频中选“播放”，短按 KEY4 暂停或继续；暂停时也可按上述步骤返回图片。
4. 未编辑时长按 KEY2 约 1 秒退出菜单；图片播放中 KEY2 下一张、KEY3 自动轮播；视频中 KEY3 暂停或继续。
5. 任意页面长按 KEY4 约 2 秒，仍进入或退出应急模式。

图片/WAV、节目与媒体菜单、字幕、屏幕调节、音量、暂停循环及应急功能保留。返回图片后 WAV 从头重启，配置保留。
