# 源码范围

本候选只包含当前工作区已经验证的图片固定索引分辨率标签，以及为 SD 目录扫描、RV16 文件头和 FAT 超时路径所做的寄存器隔离优化。没有恢复或继续冷启动修复实验，也没有新增帧缓存、PLL 或大字库。

稳定 bit 的 BMP 标签映射为：索引 0/2/4 显示 1280X720，索引 1 显示 960X540，索引 3 显示 640X480。用户通过调整 TF 卡图片顺序后已确认板上标签与图片相符；确认的是标签匹配结果，当前目录的具体顺序未重新读取。

最终源码输入的逐文件 SHA256 在 `build_inputs.sha256` 中；TD 生成 bit 的输入清单在 `build_manifest.sha256` 中。
