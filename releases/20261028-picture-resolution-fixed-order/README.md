# 图片固定顺序分辨率显示版本

本目录是最终稳定版 `20261028-picture-resolution-fixed-order`，已完成综合、P&R、bitgen、功能回归及用户板级标签确认。

## 功能

- HDMI-B 在图片右上角显示紫色分辨率标签。
- 标签采用固定 BMP 零基索引映射，不在运行时计算图片宽高：
  - 0、2、4 -> `1280X720`
  - 1 -> `960X540`
  - 3 -> `640X480`
- 视频模式、转场、无效图片和图片显示关闭时隐藏标签。
- 原有图片、WAV、视频、双 HDMI 菜单、字幕、音量和轮播功能保留。
- 本版本不包含冷启动修复实验改动。

## 烧录

使用 `av_media.bit` 进行安路 TD 下载或 Flash 固化。用户已手动调整 TF 卡图片顺序，并确认板上图片与标签对应。WAV/R16 文件不占 BMP 索引。`TF_CARD_ORDER_20261028.md` 是调整前的 Windows 目录记录，不代表当前 TF 卡顺序；若再次整理卡片，需重新逐张核对。
