# 源码范围

本目录中的 `source_snapshot` 是本次冷启动 bitgen 使用的完整源快照，不是当前工作区的实时映射。稳定候选的功能基线是发布目录 `20261026-media-return`；本次唯一功能改动为：

`rtl/sd/sd_card_top.v`

该文件加入 SD 上电保持、初始化有界监督、失败重试和成功锁存。快照内其余 RTL、约束、仿真和生成文件与本次冷启动构建一起保留，便于复查 bit 与源的一致性。

当前工作区中仍有其他未提交改动，尤其是图片原始分辨率 OSD 实验；不要用工作区的 `td_prj/av_media_Runs/phy_1/av_media.bit` 替换本目录 bit。
