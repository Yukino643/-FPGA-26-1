# 20261027 Flash 冷启动稳定候选

## 使用的 bit

烧录文件：`av_media.bit`

SHA-256：`08FB2D34D16536D2D74CB753FC438774188DADBAFDAC2D853CBC9421107426CA`

该 bit 以 `20261026-media-return` 为功能基线，只叠加 `rtl/sd/sd_card_top.v` 的 TF 卡冷启动监督与重试修复。没有叠加“图片右上角原始分辨率数字”实验，也没有改变 HDMI、菜单、音频、字幕、视频返回和按键逻辑。

## 本版保留的功能

- HDMI-B 720p 图片、WAV、有声视频、暂停/循环和双缓冲显示。
- HDMI-A 全幅 640×360 监视菜单，节目、媒体、屏幕、音量和外设操作保持不变。
- 多分辨率 BMP 等比缩放、字幕、标题、运行时间、波形、应急模式和蜂鸣器联动。
- 图片/视频模式切换、视频返回图片的较短淡化、可调轮播周期和音量控制。

## 冷启动修复

复位后先保持 SD 三层逻辑约 100 ms，随后给初始化约 2 s 的有界窗口。初始化失败或无响应时从 CMD0 重新开始，成功后停止监督计时器，不干预正常扇区事务；同拍成功优先于超时。该修复只作用于 `sd_card_top.v`。

## 烧录建议

1. 先校验本目录 `SHA256SUMS.txt`。
2. 在 TD 中选择本目录的 `av_media.bit` 进行下载或 Flash 固化。
3. 使用现有 TF 卡素材，不需要替换卡内容。
4. 首次上电等待约 10 秒，确认 HDMI-A 菜单、HDMI-B 图片和声音均出现；然后完全断电再上电重复测试。
