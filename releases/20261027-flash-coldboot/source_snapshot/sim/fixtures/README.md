# 官方 BMP 首扇区回归数据

三个 hex 文件依次保存安路提供的草莓、苹果、西瓜 BMP 的前 512 字节，未经修改。
来源：`HX4S20_Contest_202606/7_lab_ex_2026_nosoft/*/lab_ex4_tf/doc/TF卡图片/` 中的 `*_640x480_24bit_显示正常_工程适配版.bmp`。

三图均为 640×480、24 位、无压缩、文件长 921654 字节，首扇区最后一个字节为 FF。
测试覆盖扫描和装载两条头部读取路径，确保偏移 34 之后的图像数据不再改写偏移 30～33 的压缩字段。
这些夹具只验证 BMP 解析器，不模拟 FAT32 或真实 SD 电气接口。
