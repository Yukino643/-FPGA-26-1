# HDMI-B音频控制契约

- 主节目六卡索引1是音频二级页入口；波形开关移到二级页索引2，仍为cfg[1]，不得丢失功能。音频页0音量/1静音/2波形/3恢复默认，保持两行两列和逐级返回。
- 音频配置5位{mute,level[3:0]}，level0..10，默认0x0A；静音不清原level，恢复默认只恢复节目音量/静音/波形。
- 音频与已有字段共用payload稳定至ACK的toggle邮箱；预览只影响HDMI-A，active仅在VS更新，busy禁止改正文。
- 输入是audio_player左对齐的signed16 PCM，低8位为0。16位有符号样本乘0..256增益的积可直接成为24位样本；256精确保持原音量，0精确静音，不允许无符号右移/负数变正/先截到16位损失小音量精度。
- 增益每4个48kHz事件移动1，最大21.33ms；两声道用同一增益。不改变原48kHz时基或SD FIFO。
- 正常音频与警笛旁路共用两级寄存相位；最终valid/data_valid与样本同步，波形使用最终输出；FIFO空定时静音不能冒充真实PCM，警笛不受节目静音影响。
- 新字音/频/量/静使用32px逻辑列掩码、一拍寄存；原1024x32+128x32字体银行不扩深。不能仅凭RTL数组大小承诺BRAM不变，必须P&R报告验证。
- 必测所有档位、双声道符号/满幅/随机、静音恢复、渐变、警笛、复位、两个异步时钟提交/取消/忙保护、长按抑制、音频页栅格与实际缩放流水。新增输入的旧测试实例必须接确定默认值。
- BRAM9K<=57、BRAM32K<=4、PLL<=3、video setup>=0.15ns，其余域内setup/hold非负；旧SDRAM跨域负余量单列。完整回归和当前输入bit清单通过后独立归档，未上板不能声称声音已验证。
- 菜单ASCII ROM行地址仅依赖绝对y行带，不能通过x/卡片命中再选择；绘制资格与字模保持同拍。未命中区域可读取无关字模以缩短地址路径。
- FAT目录簇号资格在字节28寄存、字节31消费；字节27刚更新低半簇号，不能在字节27用旧寄存值比较。连续每拍输入、非法/合法相邻项及重扫必须验证；不增加扫描扇区或改变发现事件时刻。
