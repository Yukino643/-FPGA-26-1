# HDMI-B预设滚动字幕

## 显示与排版

HDMI-A负责操作，HDMI-B底部显示字幕。深色半透明条、青色细线和固定“通知”标记，白色原生32像素汉字从右向左移动。左右留32像素、底部留8像素；波形仍在576..672，字幕条672..712，两者不重叠。字幕开启且时间开启时，时间自动移至右上80..112，关闭字幕后恢复原位置。

默认关闭字幕，内容为欢迎语，正常速度。字幕开关独立于原有图层开关；原图层开关仍控制固定标题/模式等已有内容，不是频谱功能声明。应急层仍在字幕后级覆盖，没有增加应急页面功能。

## 菜单

主菜单保持两行三列：图片/波形/时间，字幕/周期/屏幕。原“图层”位置改为“字幕”入口；进入后四卡为字幕、内容、速度、图层。

| 卡片 | 设置 |
|---|---|
| 字幕 | OFF/ON |
| 内容 | 01WELCOME：欢迎体验双屏多媒体系统；02 EVENT：活动正在进行 欢迎参与体验；03 MEDIA：图片 音乐 字幕 精彩呈现 |
| 速度 | SLOW 30、NORM 60、FAST 120，单位像素/秒，按60Hz视频时序计算 |
| 图层 | 原cfg[3]固定文字图层开关，保留此前功能 |

1. CONTROL上用KEY2/KEY3选中“字幕”，KEY4进入。
2. KEY2/KEY3选择四张卡片；KEY4进入编辑，右上显示EDIT。
3. 编辑时KEY2减小/关闭，KEY3增加/开启；内容和速度到边界停止，不越界循环。
4. KEY4确认，HDMI-B在帧消隐应用。没有确认前只改变菜单预览。数值后星号表示预览与实际值不同。
5. KEY2长按约1秒后松开：先取消编辑，再次长按返回CONTROL（光标停在字幕），再次长按退出菜单恢复切图。每次需松开再按。
6. 二级页KEY3长按取消并返回CONTROL；主菜单KEY3长按仍切换外设页；KEY4长按约2秒仍只操作应急，不误确认。

示例：从CONTROL开机光标“图片”开始，KEY3短按3次选中“字幕”，KEY4进入；默认选中字幕开关，KEY4进入编辑，KEY3开启，KEY4确认。选择“内容”，KEY4编辑，再按KEY3选择活动通知，KEY4确认。

WAIT表示上一笔提交尚未收到帧边界ACK；可以预览，但不能覆盖在途正文，等待后再KEY4确认。切换内容/速度或重新开启字幕后从可读起点重新滚动。复位和断电后设置恢复默认，没有加入参数Flash保存。

## 资源与同步

- 修改前备份：build/720p/backups/20261021-before-subtitle，源码压缩包和原板验bit均有SHA256校验。旧发布20261021-screen-menu-cjk32保持可回退。
- 字幕cfg5位={speed[1:0],preset[1:0],enable}，默认0x08。与图层/屏幕参数共用已有toggle/ACK；正文独立保持到ACK，视频域在VS原子复制。
- 借鉴老师subtitle_scroll_24的实际用字ROM、定宽坐标和帧消隐推进。复用HDMI-B现有同步OSD字库端口，按不同Y区间服务标题、时间、字幕；不增加视频输出流水级、PLL、DSP或帧缓存。
- HDMI-B字库只追加22个实际用字，旧33字索引不变，总55字，仍在原64格范围。HDMI-A增加字/内/容/速四个字，小扩展bank避免主字库直接翻倍。
- 字幕32格循环共1024像素，初始文字可见；偏移10位自然回绕，无除法、无模运算电路。慢速每两帧1像素，正常每帧1像素，快速每帧2像素。
- 参数改变在消隐后重启滚动；每帧有效区域偏移保持，不允许行内推进导致斜字和撕裂。

## 验证与边界

控制器覆盖开关/预设/速度边界、两级返回、取消、忙保护、原图层功能和长按抑制。CDC覆盖正文/预览隔离与VS原子提交。字幕测试使用独立屏幕坐标参考，核对三条文本、半透明背景、通知标记、裁剪、1023到0回绕、30/60/120速度与时间避让；实际顶层流水测试覆盖字幕开关两种状态的RGB/DE/TLAST相位。

最终完整回归、资源、时序及烧录文件以新发布目录README为准。物理板上的字体观感、滚动流畅度、音频和长时间播放需实测。本功能为预设文本，未实现任意UTF-8文本加载或串口编辑。

## 底层边界审查

| 审查项 | 本轮结论 |
|---|---|
| 寄存器访问 | 仅新增RTL配置寄存器，不涉及CPU外设寄存器读改写；在途正文忙时保持 |
| 并发与内存 | 无DMA或CPU缓存；跨时钟正文使用稳定邮箱和toggle/ACK，预览不驱动主画面 |
| 中断与调度 | 按键为RTL长短按事件分类，无中断优先级或RTOS修改；保留长按抑制短按 |
| 时序 | 偏移只在VS推进；配置在帧消隐应用；RGB、字模列和背景保持一拍OSD同步 |
| 初始化 | 复位字幕关闭、欢迎语、正常速度，偏移和慢速相位确定；不增加时钟或PLL |
| 边界 | 菜单内容/速度饱和0..2；文本32格，偏移10位回绕；字模追加不改变原索引 |
| 兼容性 | Verilog-2005、TD6.2本机构建；字模可重复生成，不依赖综合器解析Unicode字面量 |
| 应急与恢复 | 后级应急覆盖及蜂鸣器优先级保持；旧板验源码和bit已独立备份，可回退 |
