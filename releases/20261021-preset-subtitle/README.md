## 操作

HDMI-A 主菜单仍为六卡：图片/波形/时间，字幕/周期/屏幕。用 KEY2/3 选中字幕，KEY4进入。
字幕二级页：字幕开关、内容、速度、原图层开关。KEY2/3选卡，KEY4编辑，KEY2减小/关闭、KEY3增加/开启，KEY4确认并在HDMI-B帧消隐生效。
默认关闭，欢迎语，正常速度。三条内容：欢迎体验双屏多媒体系统；活动正在进行 欢迎参与体验；图片 音乐 字幕 精彩呈现。
慢/正常/快三档约30/60/120像素每秒；字幕底条采用深色半透明底、青色细线、通知标记与原生32像素白色中文。开启字幕时运行时间移至右上，波形区域保持。
KEY2长按逐级取消编辑、返回CONTROL、退出菜单恢复切图；每次松开后再按。KEY4长按应急保留。详细操作见 PRESET_SUBTITLE_20261021.md。
字幕设置复位恢复默认；本轮为预设文本，未增加任意UTF-8文本读取、串口编辑或参数Flash持久化。

- 完整功能回归75/75；未变依赖按哈希复用，当前菜单两项重新运行。

- 当前源码TD综合、完整P&R、hold修复、bitgen完成，check_reports零失败；菜单/邮箱/渲染器/颜色/OSD寄存器与字体、缩放RAM入出路径通过定向检查。
