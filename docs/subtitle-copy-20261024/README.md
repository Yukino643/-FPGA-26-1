## 实现与边界

- `scripts/gen_font_720.py`是文案与字集的生成入口；已同步RTL文本表、字模和标签索引。正文每条仍为64格/2048px，实际字模从50增至60，ROM深度仍为2048×32，未扩大bank。后续本次完整P&R实测BRAM9K仍为57块，资源及时序详见PHYSICAL_RELEASE.md。
- `osd_engine_720.v`只延长滚动结束计数：有时间1248→1408，无时间1536→1696。最长19格=608px，结束位置为窗口宽736/1024 + 正文608 + 空白64。三句统一使用最长包围盒；较短句离场空白会更长。
- 不改变像素时钟、窗口、字号、颜色、按键、菜单中文、速度档、配置提交与复位机制；没有增加像素路径加法、除法、乘法或透明混合。
- 原14格滚动终点会使新欢迎语最后160px尚未完全离场就归零，因此文案更换必须同步计数与测试。
- `render_main_ui.py`独立屏幕参考与整圈导出器已更新。测试仍采用独立固定文本索引，不读DUT文本表充当期望值。
