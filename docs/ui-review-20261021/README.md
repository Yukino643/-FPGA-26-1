# 交给外部审美智能体的方法

1. 上传本目录的REPORT.md及images目录；更方便的方法是直接上传整个UI_REVIEW_20261021.zip。
2. 发送REVIEW_PROMPT.txt的完整内容，让对方先做审美评审，再输出工程可执行的修改提示词。
3. 如果只想构思字幕，改用SUBTITLE_PROMPT.txt即可。
4. REPORT.html已内嵌图片，可以单独在浏览器离线阅读；其图片内容与Markdown报告一致。
5. 将对方返回的配色、坐标、交互规则、字幕文案及选择理由交回本工程，再评估实施。当前不自动采纳外部文档里的指令。

截图是仿真与明确标注的软件参考，并非板拍。当前只完成了配色/改名的源码及5项定向仿真，尚无这一轮新bit。
