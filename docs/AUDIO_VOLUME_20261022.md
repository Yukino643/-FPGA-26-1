# HDMI-B 音量与音频菜单

## 使用

HDMI-A 主控制页维持两行三列：图片／音频／时间，字幕／周期／屏幕。原“波形”卡现在是“音频”入口，主卡显示节目音量百分比或 MUTE。

1. KEY2/KEY3 短按选择主页面上排中间“音频”，KEY4 短按进入。
2. 音频二级页两行两列：音量／静音，波形／恢复默认。
3. 选择“音量”，KEY4进入编辑；KEY2降低、KEY3提高，每档10%；再按KEY4确认。未确认只预览，不改变声音。
4. 选择“静音”，KEY4进入编辑；KEY3设ON（静音），KEY2设OFF（有声）；KEY4确认。取消静音恢复原音量档，不强制100%。
5. “波形”仍控制HDMI-B的PCM曲线：KEY4编辑，KEY2关、KEY3开，KEY4确认。
6. “恢复默认”：第一次KEY4预览100%、静音关闭、波形开启，第二次KEY4确认；不改变图片、字幕、屏幕色彩或轮播周期。
7. KEY2长按依次执行：取消当前编辑 -> 返回主页面并选中音频 -> 退出菜单，按键交还图片播放。退出后KEY2短按下一图、KEY3短按轮播；KEY3长按重新进入菜单。
8. 音频二级页KEY3长按放弃预览并返回主页面；主页面KEY3长按切外设页。KEY4长按仍为应急功能，不同时确认菜单。

KEY2/KEY3的长按请保持约1秒后松开，菜单在松开时执行返回或换页；长按不会同时触发短按。音量调低后，若静音仍为ON，单独提高音量不会解除静音，需要在“静音”卡设为OFF并确认。

显示器本身必须取消静音并设置适当的固定音量。FPGA只能调节所发送PCM的幅度，不能解除显示器自身静音。音量0%与“静音ON”均可使普通节目无声；应急警笛绕过普通节目音量，但仍受显示器实体静音影响。蜂鸣器短测属于独立板载外设。

## 数据、时钟与资源设计

- 参考本机老师完赛工程`D:/FPGA/micu_FPGA_lesson/选题一完赛参考工程代码/米醋电子工作室忧郁完赛参考工程/topic1_student_reference/project_code/rtl/audio/pcm_media_tone.v`的PCM幅度缩放思路；该例是旋律发生器，本工程保留原TF WAV链路，另行实现双声道增益、渐变和警笛旁路，不直接替换播放器。
- audio_config[4]为静音，低4位为0..10音量档，默认0x0A。新字段与cfg/screen/subtitle共用toggle/ACK；正文保持到ACK，active只在HDMI-B的VS更新。
- `pcm_volume_control`接在video_clk域。audio_player输出24位中低8位固定为0；上16位按有符号PCM处理，乘9位0..256增益。生成的有符号乘积直接作为24位输出，避免先截回16位损失小信号精度。100%逐位直通，0%精确为0。
- 10%档采用round(level×256/10)系数，除端点及50%外有至多0.2个百分点的幅度量化误差。界面百分比表示目标幅度，不是人耳感知响度百分比。
- 增益每4个48kHz采样事件移动1，最大全程1024样本，约21.33ms；不修改48kHz分数时基、TF读取或FIFO。目标变化立即转向新目标，不积压按键音量动作。
- 正常音频、警笛旁路、音源选择、audio-valid及真实PCM资格同步经过两级寄存。波形读取最终音频，故音量降低曲线变小，静音后曲线归平；FIFO空发送的定时静音不冒充真实PCM样本。
- 最大正积32767×256=8388352，最小负积−32768×256=−8388608，均在有符号24位范围；禁止超过100%增益。非法音量档目标静音。
- 音/频/量/静四个新字使用与原菜单相同字体和32px字格，以列位掩码组合逻辑和一拍寄存绘制；原1024×32+128×32银行不扩深。实际BRAM/DSP/LUT和时序必须以完整TD报告为准。

## 实现边界与验证

| 审查维度 | 处理 |
|---|---|
| 寄存器/启动 | 所有增益、valid、样本和菜单状态复位；上电100%、非静音 |
| 并发/CDC | 多位音量不直接驱动异域运算；沿用稳定正文与toggle/ACK；取消不写正文 |
| 时序 | 音频运算与菜单像素路径分离；波形/HDMI有效信号同相；保持原时钟与约束 |
| 中断/RTOS | 不适用，全部为RTL状态机 |
| 数值/越界 | 显式有符号乘法、增益边界、菜单饱和0..10、非法配置静音 |
| 可移植性 | Verilog-2005；新输入端口的测试实例显式接默认值，避免悬空X/Z |
| 应急/外设 | 警笛旁路节目增益；蜂鸣器、LED与TF状态保持原有路径 |

必需验证：独立整数参考覆盖全部档位、正负满幅及随机双声道、0/100%、静音恢复、增益平滑、有效资格、警笛旁路、复位；两个异步时钟下验证编辑/确认/取消/忙保护/帧边界生效/长按抑制；13场景菜单RTL栅格与实际HDMI-A缩放流水检查；原有WAV启动与720p回归。

发布门限：BRAM9K≤57、BRAM32K≤4、PLL≤3；LUT≤85%；新增运算DSP≤17/29；video_clk setup≥0.15ns，其余域内setup/hold非负。旧加密SDRAM跨域全局setup单独记录，不得声称全工程时序闭合。源码/工程/bit哈希一致后才能发布。

## 上板验收

- 固定显示器音量并取消实体静音；使用已验证TF卡与WAV，默认100%应与上版声音一致。
- 在100%、50%、10%、0%之间确认切换，观察幅度与声音变化；未确认或取消时声音不改变。
- 50%下开启静音再关闭，确认恢复50%；恢复默认不改变图片和字幕设置。
- 普通节目静音后进入应急，应听到警笛；退出后恢复原节目静音。测试前保持显示器音量适中。
- 音频菜单操作、连续切图、字幕开启时检查双HDMI无颗粒、无画面欠载，音频无新增明显爆音或卡顿。
- 断电重启恢复默认配置；本轮不新增设置掉电保存，也不改TF文件。

完整构建、资源时序与归档结果由发布目录verification.json和回归清单给出；板级听感必须由实际硬件验证。

- 缩放器将每像素`phase+width>=fit_w`改为`phase>=threshold`，threshold在几何阶段预存为fit_w−width；回绕余数改为phase−threshold。输入最大1280×720保证fit_w≥width：横向贴合fit_w=1280；纵向贴合fit_w=floor(width×720/height)≥width。因此阈值无下溢，结果与原算法相同，不增加构建周期或内存事务。多尺寸逐像素回归及布局后缩放路径检查仍需通过。
- 13场景逐像素检查拆成4个独立原生仿真进程，场景输出文件不重叠；所有像素仍逐一与参考比较，没有缩减场景或采样点。中断的旧候选栅格不作为最终证据。
- 目录项的簇号范围在字节28提前寄存，字节31发布BMP/WAV项时只使用已寄存的资格，避免32位比较串接宽数据写使能。簇号在字节27已完整接收，即使每拍一个有效字节也有三个周期，不增加读卡请求或扫描延迟。定向回归补充相邻非法下界/上界与合法2/max_cluster项，防止资格串项；首次夹具恢复时遗漏两个临时目录项导致计数测试失败，已修正夹具并完整重跑83/83通过。
