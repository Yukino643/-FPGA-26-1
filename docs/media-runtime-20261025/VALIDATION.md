| 同域路径 | 最差setup / ns | 最差hold / ns |
|---|---:|---:|
| video_clk | +0.516 | +0.027 |
| sd_card_clk | +0.216 | +0.036 |
| ext_mem_clk | +0.144 | +0.022 |
| hdmi_5x_clk | +0.840 | +0.223 |

本表取详细报告中各`clock -> clock`自环路径组。时钟端点汇总的HDMI hold为+0.041ns，统计范围不同，不与该自环组+0.223ns混用。video_clk满足本工程+0.15ns门限；其他同域setup/hold均非负。全局setup仍为−6.565ns，来自旧加密SDRAM跨域路径，须单列；全局hold为+0.022ns。**本记录不声称全工程时序闭合。**

媒体播放器、FAT/簇映射、6VS换页和切换控制的定向时序均通过；缩放、菜单/配置/字库/颜色/OSD/音量的定向检查也通过。摘要及当前bit绑定保存在发布`validation/`。

两次未通过的布局保留在`20261025-media-runtime-final`及`20261025-media-runtime-final-seed17`构建档案，不能使用其中bit发布。修正FAT超时控制的使能扇出后重建，未放宽约束，详见`ARCHITECTURE.md`。

## 已知范围与板验

- 素材为320×180、10fps、RGB565 RV16，经4倍最近邻放大到720p；FPGA不解码MP4。97帧、9.7秒素材SHA见发布`verification.json`。
- 暂停冻结视频换页，HDMI时序、菜单、时钟、字幕和应急继续运行；慢帧保持最后完整画面。
- 视频无音轨。WAV后台运行但节目PCM静音，应急警笛保留；返回图片恢复WAV当前播放位置。
- 未写TF卡、未烧录、未提交或推送Git。
- 板验按`USAGE.md`：图片/WAV→视频循环→暂停/继续→暂停返回图片→再次视频→应急进入/退出，并检查双屏、字幕与色彩设置。

最终发布脚本拒绝缺失/过时测试、资源超限、同域时序未过门及bit/源码不一致；以发布`verification.json`、`SOURCE_SHA256.json`及`SHA256SUMS.txt`为准。
