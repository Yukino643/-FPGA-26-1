上电直接节目控制页、聚焦图片，不再有参数首页。卡序均逐行从左到右；没有触屏/鼠标/方向键。

|页面|页眉|卡片0/1/2；3/4/5或0/1；2/3|作用|
|---|---|---|---|
|节目|PROGRAM CONTROL|图片/音频/时间；字幕/周期/屏幕|图片/时间开关、音频/字幕/屏幕入口、周期预览确认|
|音频|HDMI-B AUDIO|音量/静音；波形/恢复默认|只调HDMI-B节目PCM，不改实体屏音响档位|
|屏幕|HDMI-B SETTINGS|亮度/对比度；色温/恢复默认|只调HDMI-B背景图片像素，不是HDMI-A或实体背光|
|字幕|HDMI-B SUBTITLE|字幕/内容；速度/标题|底条开关、三预设、三速度、顶部标题+模式共同开关|
|外设|PERIPHERAL TEST|外设/蜂鸣器；按键/板载灯|TF初始化、200ms测试请求、事件高字节、真实LED编码|
|播放按键模式|PLAYBACK KEYS|保留节目六卡|无焦点/状态字；KEY2/3交还图片/自动播放；底部一行提示|

|值区域|全部合法值/文本|语义与边界|
|---|---|---|
|图片、时间、字幕、标题、波形|ON / OFF|状态值不是图片名；主卡无当前图片编号或缩略图|
|音频主卡|0%～100%（每档10%）或MUTE|静音时主卡MUTE仍属普通VALUE色；不等于实际声压百分比|
|音量卡|0%～100%|预览与10段条同步；确认前声音不变|
|静音卡|ON / OFF|ON=静音，绿色；OFF=未静音，红色，现语义可能反直觉，必须审查|
|周期|2S/3S/5S/10S|无1S；设置档位不等于开启自动播放|
|亮度|−64/−48/−32/−16/0/+16/+32/+48/+64|中档为单独0；实际ASCII减号是`-`，不是数学U+2212|
|对比度|50/63/75/88/100/113/125/138/150%|离散档，实际系数64+16×档位，128为100%，UI取整|
|色温|COOL/NORM/WARM|通道偏置−20/0/+20；不是Kelvin校准|
|恢复默认|RESET → CONFIRM|先预览恢复，再确认；屏幕/音频分别恢复本组|
|内容|1/3、2/3、3/3|无完整文案预览|
|速度|SLOW/NORM/FAST|像素速度见第10节|
|外设|READY / WAIT|目前主要由sd_init_done决定；不是FAT32/所有外设总诊断|
|蜂鸣器|IDLE / TEST|请求态，不是声音反馈；可重复触发短测试，应急优先|
|按键|CNT00～CNTFF|16位事件计数的**高8位**十六进制；并非每按一下显示加1|
|板载灯|LED0～LEDF|四bit真实输出编码；不能按KEY4任意开关四灯|
|非法参数|ERR|仅非法档位/索引渲染；不是整机故障屏|

上电默认：图片/波形/时间ON，标题/字幕OFF；音量100%、静音OFF；亮度0、对比100%、NORM；周期2S；自动播放初始OFF。
测试图中字幕ON、CNTAB、LED3、113%、WAIT等是夹具值，不可当默认值。LED上电/初始化未完成时1111；随后
bit3=应急或BMP/WAV超时、bit2=音频存在、bit1=有效画面、bit0=心跳。是否应以图标替代HEX是提案，现没有逐灯图示。

三键20ms消抖；菜单短/长主要在松开后分类，无连续按住自动逐档功能。KEY4按住≥1s被菜单当长按、抑制短按；
**应急控制器独立阈值约2s**，长按期间切应急。1～2s的KEY4不会是普通确认，也不保证触发应急；不要把两阈值合并成1s。
物理KEY2/3/4对应顶层端口key1/key2/key3，别按RTL端口名误教按键。

已知交互边界仍在：节目页cfg_dirty是全局；在A卡留下预览后移到B卡，再按KEY4可能提交A的遗留预览；进入二级入口会丢弃原预览。
当前EDIT绘图是聚焦卡pending/二级edit，不是全局dirty，因此移开A卡后页眉可能READY但A卡值/边仍琥珀。
这个问题应在审查中单列为状态可理解性，不能谎称已解决，也不要让它吞掉整轮审美评审。
二级预览只在HDMI-A shadow中显示，HDMI-B在确认后帧边界生效；建议“实时预览声音/颜色”属于改契约，需另行说明。
