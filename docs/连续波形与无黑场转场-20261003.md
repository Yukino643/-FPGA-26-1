# 连续 PCM 波形与无黑场转场

## 问题及实现

| 问题 | 原因 | 本轮实现 |
|---|---|---|
| 波形呈矩形台阶 | 每点保持16列，未连接相邻点 | 有符号线性插值；当前/下一列端点间补齐陡坡，常规3px连续绿线 |
| 图片切换中途黑屏 | 旧版本采用单页淡黑再切页 | 默认双页实际横向推移；旧图向左、新图从右侧进入 |
| 动画末尾可能闪旧页 | A页预取与页提交存在帧交接 | 末帧完整显示目标B，A预取目标页后再交回A；此前loader保持暂停 |

## 老师资料及适配

- 第十二讲 `promax_audio_waveform.v`：保留真实PCM valid、32点双bank、完整组VS发布及峰值表；顶层DECIMATE=120和跨帧采集继续使用。新绘图层连接相邻采样点，末点保持自身，未初始化/窗口外数据不进入曲线。
- 第十讲 `frame_blend.v`：保留双页互补权重和帧边界推进，模式1为交叉淡化；这属于颜色混合，不是空间模糊。
- 默认模式2：两路读引擎每行先读偏移列至行尾，再回绕读行首；源列回绕不推进行。拼接边界与读取偏移同步变化，形成实际横向运动。

| 模式 | 效果 | 时长（约60Hz） |
|---|---|---|
| 2，复位默认 | 旧图左移、新图从右侧进入 | 40步，每步16px，约0.67秒 |
| 3 | 纵向揭示 | 30步，约0.50秒；不是实际纵向位移 |
| 0 | VS帧边界直切 | 一次帧边界 |
| 1 | 双页交叉淡化 | 32步，alpha每步8，约0.53秒 |

物理KEY4短按按 `2→3→0→1→2` 循环；模式在下一次图片提交时锁存。KEY4长按仍为既有应急切换。

## 时序与所有权

两页在动画期间保持只读。显示页号和位移均在VS发布，payload两级同步，帧toggle三拍同步再由挂起事件应用；在途突发完整收尾才重启。突发在源行尾、输出行尾和帧尾截短，两路FIFO每个活动像素同时排空。欠载显式统计，不用错误坐标的另一页掩盖失败。

RGB、DE和坐标保持既有拍相位。标题、模式、时间及PCM图层固定在屏幕位置，只有背景图片推移。
