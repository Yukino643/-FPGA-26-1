## 3. 双屏关系与真实显示尺寸

|对象|真实输出|绘制方式|审美关注|
|---|---|---|---|
|HDMI-A 监视控制台|1280×720，60 Hz，视频输出|640×480 逻辑画布，等比 1.5 倍映射到 x[160,1120)、y[0,720)，左右各 160px 黑边|7 寸屏的可读性、是否像正式产品、中央 4:3 布局是否浪费空间|
|HDMI-B 主节目|1280×720，60 Hz，含 HDMI 音频|图片/转场 → 色彩调节 → PCM 波形 → OSD → 应急覆盖|照片主体、文字层级、字幕动效和波形是否抢画面|

映射关系：`logical_x=floor((physical_x−160)×2/3)`，`logical_y=floor(physical_y×2/3)`；视口外为黑色。菜单目前不是横向铺满 16:9，也不能写成“仍输出 640×480”。顶层有历史注释和 `hdmi_video_only_640x480` 模块名，但实际时序以 1650×750 总时序、1280×720 有效区为准。

HDMI-A 不读第二套图像帧缓存，无触屏、鼠标、方向键或联网。请不要用网页/手机控件方案假装可以直接移植。**可以严厉批评当前黑边和空间比例，并给无新增帧缓存的替代布局；不要把现状约束误当审美最优。**

## 4. HDMI-A：页面与内容

上电直接显示节目控制页，默认焦点在“图片”；旧详细参数首页不再出现。菜单主要标题是中文，页眉和状态值仍大量使用英文，并非完全中文化。

|页面|页眉文字|从左到右、从上到下的卡片|当前实际用途|
|---|---|---|---|
|节目控制|PROGRAM CONTROL|图片／音频／时间；字幕／周期／屏幕|图片和时间开关；音频、字幕、屏幕进二级页；周期换档|
|音频二级|HDMI-B AUDIO|音量／静音；波形／恢复默认|0～100%，每档 10%；独立静音；PCM 波形开关|
|屏幕二级|HDMI-B SETTINGS|亮度／对比度；色温／恢复默认|只改变 HDMI-B 图片色彩，不调 HDMI-A，不是屏幕实体背光|
|字幕二级|HDMI-B SUBTITLE|字幕／内容；速度／标题|滚动条开关、三句预设、三档速度、顶部固定标题/模式开关|
|外设检测|PERIPHERAL TEST|外设／蜂鸣器；按键／板载灯|TF 初始化 READY/WAIT；200ms 蜂鸣器短测；事件高字节及 LED 编码|
|播放按键模式|PLAYBACK KEYS|保留节目卡片，但无焦点/页眉状态块|按键交还播放；底部出现一行小字操作提示|

实际值举例与限制：

|区域|显示形式|不能夸大的地方|
|---|---|---|
|图片、时间、字幕、标题、波形|ON/OFF，预览变化可带 `*`|主卡不显示图片缩略图，也不直接显示当前图片序号|
|音频主卡|100% 等或 MUTE|百分比是数字 PCM 幅度目标，不是实际声压或人耳响度百分比|
|音频二级静音|ON 表示静音，OFF 表示有声|ON 为绿色、OFF 为红色，是通用值色规则；是否语义反直觉应重点审美/交互评审|
|轮播周期|2S／3S／5S／10S|已删除 1S；改周期不是开启自动轮播，自动开关在播放按键模式|
|亮度|−64、−48、−32、−16、0、+16、+32、+48、+64|单位为像素通道偏移档，不是屏幕背光百分比；0 目前不显示 +0|
|对比度|50%、63%、75%、88%、100%、113%、125%、138%、150%|UI 显示按当前档位取整；不是连续滑杆|
|色温|COOL／NORM／WARM|没有 Kelvin 数值，不要拟造精确色温校准|
|字幕内容|1/3、2/3、3/3|菜单当前不显示所选句子的全文预览|
|速度|SLOW／NORM／FAST|不是速度曲线或拖拽滑块|
|恢复默认|RESET，进入编辑后 CONFIRM|不是点一次立即恢复；两个二级页各自只恢复自身配置|
|外设/蜂鸣器|READY/WAIT、IDLE/TEST|READY 主要由 TF 初始化信号决定；TEST 是输出请求，不是实际发声反馈检测|
|按键|CNTAB 等|显示事件计数高 8 位的十六进制，不是低位逐按递增的十进制计数|
|板载灯|LED3 等|真实 LED 输出编码，不是逐灯图形仪表或任意灯开关|

本次图集里的 ON/OFF、CNTAB、LED3、113% 和 WAIT 等是测试夹具设定，不能误当上电默认值。尤其节目正常图为了显示字幕卡 ON，使用了字幕开启状态。

## 8. 当前按键交互：为了审查反馈是否清楚

|场景|KEY2短按|KEY3短按|KEY4短按|KEY2长按约1s后松开|KEY3长按约1s后松开|
|---|---|---|---|---|---|
|主菜单|上一卡|下一卡|图片/时间/周期先预览，再按一次确认；其他入口进入二级页|放弃预览并退出至播放按键|控制/外设两页互换，放弃预览|
|二级页浏览|上一卡|下一卡|开始编辑|返回上一级|放弃预览并回主菜单|
|二级页编辑|降低/关|提高/开|确认，帧边界提交|取消编辑，当前仍在二级页|放弃预览并回主菜单|
|外设页|上一卡|下一卡|只在蜂鸣器卡触发约200ms短测|退出至播放按键|回控制页|
|播放按键|下一张|自动播放开关|无普通菜单动作|无菜单动作|进入主菜单|

物理 KEY4 长按约2s保留独立应急模式功能，不当确认；菜单长短按事件要区分。普通KEY2/KEY3菜单操作主要在松开后分类生效。菜单的 1s 长按分类阈值和应急 2s 阈值不是同一个阈值。

**已知尚未修的交互问题**：主菜单在A卡第一次KEY4产生预览后，短按移至B卡，再按KEY4可能提交A遗留的全局cfg_dirty预览；进入某些二级入口会丢弃预览。当前资料必须如实反映，不能把“换卡自动取消预览”写成已实现。请评估这会不会使视觉状态误导，但不要把本轮变成全面逻辑重构。

字幕/亮度/音量的“预览”只改变 HDMI-A shadow 展示，确认前 HDMI-B不变；配置邮箱保持payload至ACK，HDMI-B在帧边界应用。页眉WAIT不等于故障，状态过短是否需要成功反馈可作为低成本提案。

## 15. 动态细节与目前没有的东西

- 菜单不做卡片位移动画、圆角、阴影、抗锯齿、背景虚化或焦点呼吸；当前是即时换边框/填充/箭头。没有独立确认成功动画。可以建议替代，但不要把现代网页效果全搬进像素关键路径。
- 音量条显示shadow预览，HDMI-B声音在确认后改变；增益有平滑过渡。不能因预览条动了就假定声音已经改变。节目静音后波形随最终PCM幅度变化，实际屏幕音响仍需自行取消实体静音。
- 波形不是FFT频谱。32个采样点、顶层DECIMATE=120，约覆盖80ms的48kHz音频；完整组在帧边界发布，再逐帧平滑和消隐预计算。白噪点式装饰线不是当前目标。
- 图片切换已有交叉淡化链路；当前顶层 `tr_mode_reg=2'd1` 固定，菜单没有“转场风格选择器”。评审可以检查切换时标题/字幕是否分散注意力，但没有本轮录像，不可描述未经观察的实际动效。
- 应急是独立覆盖层：#C00000背景，y[180,220)白色整行占位标题带，y[280,300)黄色#FFDD00/红色周期条；每帧水平偏移2px。**标题仍不是“紧急疏散”中文字形**，不要按代码注释误判。它不属于本轮优先美化范围，也不能说没完成的中文标题已实现。
- 没有通用弹窗、吐司、内容缩略图、封面图、进度时间轴或内容全文预览；没有新增任意字幕输入或设置掉电保存。报告若提出这些，应明确是新提案，并判断对三分钟视频是否值得。
