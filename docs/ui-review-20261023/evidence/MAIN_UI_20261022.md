## 板测重点

1. 在原有字幕二级页分别开启标题/字幕；运行时间使用原有开关。依次检查上述8组合，尤其字幕关闭后时间保持右下。
2. 三条文案各完整滚一圈，SLOW/NORM/FAST分别检查；正常两端分段允许，同帧额外源列重复不允许。
3. 白色/明亮和暗色照片检查文字对比、局部底板、时间交集不二次压暗、字母I清楚且无实心块。
4. 图片切换、音乐/PCM波形、应急、双屏菜单及取消/确认保持；本轮不改变按键语义。
5. 软件/RTL核验不能替代双屏板验。用户已反馈本轮修改检查完成；上列细项仍是验收清单，不据此推定用户逐项执行，详见独立板验记录。

## 复查旧版时序口径

2026-10-22本轮逐Path Group复查发现：原20261022-menu-ui-p0报告的sd_card_clk域内部setup实际为−0.142ns，先前摘要没有单列。这不是本轮新增逻辑，但本轮严格检查将该域也纳入非负门限；旧报告保留原始证据，不回写历史哈希，也不能继续笼统声称旧版所有域内时序通过。

功能检查数量：回归入口在--sim-only下实际为75项；不带此参数会追加CURRENT_SOURCE_REPORTS和CURRENT_RESIZE_TIMING两项，完整数量应为77。最终发布检查要求77/77、complete=true、filter=null、sim_only=false；不能把75个功能用例的结果直接充作物理检查完成。

## 物理收敛记录补充

- 常规seed11–24的多个候选及官方TimingMedium/TimingHigh/MacroTiming策略均未同时满足所有严格门限；失败报告和构建错误日志独立保留，未发布。
- 局部自动bound在独立DB接口验证成功，但实际放置因156个单元重叠未合法化，已撤下，不改变RTL/约束。
- 官方LogicLevelOptimize综合策略（one_hot、min_ripple_len18、balance_explore、mapper_lut_delay2200、merge_tiny_lut）实测seed13 LUT14160、reg9355、BRAM57/4、DSP13、PLL3；video +0.227ns、ext内部+0.133ns、HDMI5x+1.060ns，但sd_card内部−0.418ns，故仍拒绝发布。该SD路径逻辑0级、98%延迟来自78扇出连线；下一步仅加官方高扇出物理优化，不改RTL。
- 所有候选的旧SDRAM跨域全局setup仍为−6.565ns；不能声称全工程闭合。
