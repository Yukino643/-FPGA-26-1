# 双屏系统简明操作说明

更新：2026-10-24。以下操作对应 [菜单防误操作版 av_media.bit](../releases/20261024-menu-navigation/av_media.bit)，已通过完整范围回归与综合/P&R/bitgen，待上板确认。请使用这一版；旧字幕版 bit 不含“移开卡片取消预览”的修复。

## 先记住这三点

- HDMI-A 是控制台，图片、声音、字幕和屏幕参数调整作用于 HDMI-B。
- 短按建议 0.1～0.5 秒；KEY2/KEY3 长按约 1 秒后松开，建议保持 1.2 秒。每次长按后先松开再按。
- 主控制页：**同一张卡上按两次 KEY4 才确认，移开卡片就取消未确认预览。** 已确认的设置不会因移动光标而撤销。

按键编号以开发板丝印为准，KEY1 为复位。

## 主控制页

开机直接进入，两行三列：

| 左 | 中 | 右 |
|---|---|---|
| 图片 | 音频 | 时间 |
| 字幕 | 周期 | 屏幕 |

| 操作 | 作用 |
|---|---|
| 短按 KEY2 / KEY3 | 上一个 / 下一个卡片，六卡循环；未确认预览同时取消 |
| 图片、时间：第一次短按 KEY4 | 预览开 / 关，HDMI-B 暂不改变 |
| 周期：第一次短按 KEY4 | 预览下一档，依次为 2 / 3 / 5 / 10 秒 |
| 同卡第二次短按 KEY4 | 确认预览；HDMI-B 图层在帧边界应用，周期确认后重新计时 |
| 音频、字幕、屏幕：短按 KEY4 | 进入对应二级页 |
| 长按 KEY3 后松开 | 切换主控制页 / 外设页，未确认预览取消 |
| 长按 KEY2 后松开 | 退出菜单操作，恢复图片播放按键 |

例如：图片当前开启，按一次 KEY4 预览关闭，再按一次确认关闭。要重新开启，仍在图片卡按两次 KEY4。若第一次后移到其他卡片，预览作废，图片维持原状态；回到图片卡需要重新按两次。

黄色边框和圆点表示当前选中；琥珀色数值表示待确认变化。EDIT 表示当前项有编辑/待确认内容；WAIT 表示上一笔提交尚未完成，此时可预览，等 WAIT 消失后再按 KEY4 确认，不必连续连按。

## 二级页：音频 / 字幕 / 屏幕

统一操作：**KEY2/KEY3 选卡 → KEY4 进入编辑 → KEY2 减少/关闭、KEY3 增加/开启 → KEY4 确认。** 编辑时 KEY2/KEY3 调数值，不移动光标；未确认只在 HDMI-A 预览。

| 页面 | 可调整内容 |
|---|---|
| 音频 | 音量 0～100%（每档 10%）、独立静音、波形开关、恢复默认 |
| 字幕 | 字幕开关、三条预设内容、慢/常/快三档速度、固定标题开关 |
| 屏幕 | HDMI-B 图片底图的亮度、对比度、色温、恢复默认 |

“恢复默认”第一次 KEY4 预览，第二次确认，仅恢复该页面所属设置。音频恢复默认同时开启波形。显示器自身要取消静音并设置适当音量；FPGA 音量控制不能解除显示器静音。

返回：

- 编辑中长按 KEY2：取消编辑，留在当前二级页。
- 未编辑时长按 KEY2：回主控制页，保留入口卡选中；再长按一次退出菜单。
- 二级页长按 KEY3：直接取消预览并回主控制页，选中图片卡。

## 退出菜单后：控制图片

| 操作 | 作用 |
|---|---|
| 短按 KEY2 | 下一张图片 |
| 短按 KEY3 | 自动轮播开启 / 关闭，按已确认的周期播放 |
| 长按 KEY3 后松开 | 回到主控制页 |

若图片已确认关闭，退出菜单不会自动开启；先回图片卡按两次 KEY4 开启。读卡或转场未完成时，快速连按仍可能等待处理。

## 外设与应急

外设页用 KEY2/KEY3 选卡。TF、按键、LED 卡只读；选中蜂鸣器短按 KEY4，请求短响约 200 ms 后自动停止，板上硬件开关仍会影响实际发声。LED 跟随媒体状态，不是手动开关：LED0 心跳、LED1 图片有效、LED2 检测到 WAV、LED3 应急或 SD 超时；复位/初始化时四灯全亮。

任意页面按住 KEY4 超过约 2 秒进入/退出应急，不会同时确认菜单；应急期间普通蜂鸣器测试不能覆盖警报。菜单设置在复位或重新上电后恢复默认。
