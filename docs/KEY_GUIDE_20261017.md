# 双屏系统按键与本轮板级验收

## 按键编号

以开发板丝印为准：KEY1为复位，KEY2/KEY3/KEY4参与控制。RTL的`key1/key2/key3`分别接物理KEY2/KEY3/KEY4，不要照RTL名称判断板上编号。

KEY2、KEY3菜单长按阈值约1秒，操作在松开后生效，建议按住1.2秒再松开。短按建议0.1～0.5秒。KEY4应急阈值约2秒，按住超过2秒触发一次，继续按住不会反复翻转。

## 上电菜单与播放按键模式

| 当前状态 | 操作 | 结果 |
|---|---|---|
| 上电 | 无需按键 | HDMI-A直接显示PROGRAM CONTROL，黄色边框和圆点选中IMAGE |
| 菜单内 | 短按KEY2 | 上一个卡片，四项循环 |
| 菜单内 | 短按KEY3 | 下一个卡片，四项循环 |
| 节目页 | 第一次短按KEY4 | 翻转选中图层的预览ON/OFF，`*`表示与当前生效配置不同；HDMI-B尚不改变 |
| 节目页，有未确认预览 | 再短按KEY4 | 确认该笔预览；HDMI-B下个帧边界生效。前一笔提交等待ACK时不能提交新正文，可稍候再按 |
| 菜单内 | 长按KEY3，松开 | PROGRAM CONTROL与PERIPHERAL TEST互切；未确认预览丢弃 |
| 菜单内 | 长按KEY2，松开 | 取消未确认预览并退出菜单操作；HDMI-A显示PLAYBACK KEYS，黄色选中效果消失 |
| 播放按键模式 | 短按KEY2 | HDMI-B下一张图片；后台页未就绪时需等待读卡/转场 |
| 播放按键模式 | 短按KEY3 | 自动轮播开/关 |
| 播放按键模式 | 长按KEY3，松开 | 重新进入PROGRAM CONTROL，选中IMAGE |
| 任意状态 | KEY4长按超过2秒 | 切换应急请求，在视频帧边界生效；再长按一次退出应急 |

退出菜单不会自动恢复被你关闭的图层。如果IMAGE当前OFF，先在节目页选IMAGE，短按KEY4预览ON，再按一次KEY4确认，然后长按KEY2退出，就能看图并切图。退出菜单后，HDMI-A仍保留卡片，只改变按键归属和提示，不恢复旧参数界面。

## 外设卡片

| 卡片 | 当前含义 | 短按KEY4 |
|---|---|---|
| TF CARD | SD初始化READY/WAIT；不代表完整FAT/图片读取均无错误 | 只读，不重新初始化或写卡 |
| BEEP | FPGA测试请求IDLE/TEST，无实际发声反馈传感器 | 非应急时请求约200ms，自动结束；应急时忽略测试 |
| KEYS | 事件计数高位，尚未展示完整低位计数/按键图标 | 只读 |
| LEDS | 四个真实板载LED的位组合，十六进制0～F | 只读，跟随媒体状态 |

LED0心跳、LED1图片有效、LED2检测到WAV、LED3应急或SD超时。复位/卡初始化时四灯全亮。蜂鸣器还受板上硬件开关影响；200ms短响后关闭是正常测试行为。

## 本轮板级验收

本轮仿真和构建不能代替下列实物检查，结果需现场记录。

| 次序 | 操作与通过标准 |
|---|---|
| 1 | 两屏接好后复位：HDMI-A直接四卡控制页；四个标题不重复，边框/圆点/两行提示清晰 |
| 2 | IMAGE连续按两次KEY4关闭，再两次开启：预览阶段HDMI-B不变，确认后改变；关闭时视频时序仍正常 |
| 3 | 先做一次未确认预览，再长按KEY2：回PLAYBACK KEYS，预览被取消，图层维持已确认状态 |
| 4 | 短按KEY2：下一图；短按KEY3：自动轮播开关；长按KEY3重入菜单时不应同时改变自动播放 |
| 5 | 菜单长按KEY3：两页互切；外设BEEP短按KEY4只短响约200ms |
| 6 | 任意页KEY4长按2秒：HDMI-B应急红底、白色占位条、黄色条纹；所有条纹顶/底边在整行同一高度，不应倾斜或在1024列处断裂 |
| 7 | 应急下BEEP测试不能改变警报；再长按KEY4退出，恢复原图片和图层设置 |
| 8 | 双屏连续播放并切换菜单，记录花屏/音频中断/异常重启；冷启动、长时音频和Flash断电启动另做验收 |

应急白条目前仍是标题占位，未实现真正警示文字；本轮不把色块误称为“紧急疏散”文字。
