# 炬屏界面与 PCM 波形优化

## 实现目标

- 切图默认按视频帧边界淡出至黑、黑场换页、再淡入，避免双页混合造成的旧图叠影。
- 左上显示“炬屏—双模HDMI多媒体系统”，右上显示模式，右下显示运行时间。三处文字为黑色透明叠加，不画顶部或底部色条。
- 去掉主画面的频谱柱，按老师第十二讲从实际 PCM 音频样本绘制 32 点波形。
- 保持 RGB、坐标、DE 同步；页提交和装载暂停通过明确的跨时钟同步交接。

## 老师资料对照

| 老师资料 | 本工程沿用的实现 |
|---|---|
| 第十讲 `video_fade_transition.v` | `IDLE → OUT → HOLD → IN` 的淡出、换页停留、淡入顺序；转场状态只在帧边界推进 |
| 第十讲单页亮度淡变 | 淡出/淡入只对当前 A 页乘亮度，黑帧中更新显示页，不在两张图间交叉叠影 |
| 第十二讲 `promax_audio_waveform.v` | 有效 PCM 抽样、抽取与 32 点双 bank、帧边界发布、样本水平保持、3 像素绿线、中轴线和独立峰值表 |

适配项：老师代码使用低有效复位、VS 下降沿以及内部行计数。本工程改用高有效同步复位、顶层正极性 `vs_rise_v` 脉冲和 `pixel_pos_gen` 提供的显式 y 坐标。采样 bank、抽取计数和完整组发布遵循老师代码；为适配 48 kHz 音频与较慢、可读的显示时基，当前顶层使用 `DECIMATE=120`，32 点覆盖约 80 ms。采样组未完成时跨视频帧保留 `capture_count`、抽取计数和峰值，采满后暂停写入并在下一个 VS 边界交换读写 bank、锁存峰值。静音时不合成信号，保留最近一次完整采样组；第一组发布前只显示中轴线。波形增益由高字节除以 2，并通过窗口边界饱和裁剪。

## 显示管线

```text
双缓冲图片 → 色彩调节 → PCM 波形 → 透明黑字 OSD → 应急覆盖 → HDMI_B
```

主画面标题为 14 格，每格 16 像素，起点 `(16, 4)`；模式为 4 格，起点 `(560, 4)`；运行时间为 11 格，起点 `(448, 456)`。波形占据 `(64, 376)` 至 `(575, 447)`，右侧 `(584, 376)` 至 `(591, 447)` 显示课程例程中的单点峰值表，与时钟保持间隔。非文字、非波形、非峰值像素透传图片。

## 切图一致性

1. scaler 完成后同步完成 toggle 与稳定的目标页号，目标页号先锁存，再延后一拍送入转场控制器。
2. 转场控制器在视频帧边界接受提交，并在淡出、黑帧或方向揭示完成前保持装载暂停。
3. 暂停电平经同步器返回 SD 域；视频完成后用持久 toggle 通知解除暂停，避免跨域单拍脉冲丢失。
4. 显示页基址通过两级同步进入 SDRAM 读时钟域。读引擎应用新帧/新页基址的周期禁止同时发送旧 `base_r` 地址请求。
5. 页面可见标志在视频帧边界采纳，防止初始空帧中途出现首张图片。

默认模式为课程建议的 16 帧步进淡变：旧页逐帧淡到黑，在黑帧切页并等待新页预取，再逐帧淡入；左右/上下揭示和直切保留为按键可选效果。淡入使用扩展位饱和加法，避免 8 位 alpha 在满量程回绕。

波形的有效信号与 HDMI 音频包节拍分离：FIFO 空时 HDMI 仍按 48 kHz 发送静音，但该节拍不会被当成 PCM 样本。正常模式只采集 WAV FIFO 实际读出的样本，应急模式采集警笛样本。若 TF 卡只有 BMP、没有可播放 WAV，正常模式不会出现起伏波形；工程当前 WAV 播放链要求 PCM、48 kHz、16-bit、双声道及标准 44 字节头，不能用伪造的波形掩盖输入缺失。
