## 已出图实现链路

TF SPI 初始化/读扇区 → 扇区扫描 BMP 头 → 解码 BGR 为 RGB888 → 两像素 RGB565 打包 → SDRAM SRC_BUF → scaler 读源/双线性缩放 → DISP_BUF 的 `RRGGBB00` → 帧预取引擎 → 异步 FIFO → 双页混合器 RGB888 → OSD/色彩/应急合成 → RGB/AXIS → HDMI_B。

源写完成只能触发 scaler；scaler 完成持久 toggle 经跨域同步后才允许提交显示页。双缓冲提交沿用既有垂直消隐时切页机制。D3 的 BMP 解析、SDRAM 初始化/busy 接受门控、命令期间读返回路由、scaler DQM=0 的修复均保留。

参考依据：学长 `Main/q3q4/lab_ex_6_tf_sdram_hdmi/src/top.v` 采用 `video_read_data[31:8]`；本地 TD 生成 FIFO `rtl/pll/afifo_32_16_256.v` 在 `SHOW_AHEAD_EN=1` 时采用 `rd_addr + rd_en_s`。25 年题目截图为 HX4S20C 以太网图像传输题，可借鉴同板卡的存储/显示接口。
