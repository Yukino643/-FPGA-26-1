# 选题一当前工程重新审计（2026-10-23）

## 1. 结论和核对依据

基础播放链路和官方五个可选扩展方向均有当前顶层实现，不再缺必须新建的大功能。现阶段以赛前部署、稳定性实测、交互细节和交付材料收尾为主，不建议为凑功能加入FFT、逐图音轨或第二块板。

这不等于所有官方评价维度已经最终验收完毕：Flash脱机启动尚未获得用户明确确认，长时间压力/异常素材测试缺少完整记录，旧加密SDRAM相关跨域setup仍为负。已有通用设计材料，需要进一步整理为与最终镜像一致的参赛提交版本，不能写成项目完全没有文档。

## 4. 不建议为了“达标”继续增加的功能

| 项目 | 判断 |
|---|---|
| FFT频谱 | 已有波形满足官方方向，不必增加 |
| 第二块FPGA联动 | 单板当前可用；LUT75.71%、BRAM9K89.06%，不因720p或双HDMI自动要求双板 |
| 逐图绑定音频 | 非官方逐字必做，且用户此前要求慎重、最后评估，继续暂缓 |
| 任意字幕编辑/外部网络/触屏 | 不属于现有赛题最低要求，未实现不能宣传，但不应作为本阶段必补 |
| 应急中文字 | 当前应急标题仍是白色占位条，若宣传“应急信息发布”应如实注明；用户已表示不优先完善应急，主场景可选展陈/数字广告，不强行追加 |
| 外设页完整诊断 | FAT/预取/错误/PLL/欠载未全显示，KEYS仅显示高8位；属于原监控构想的未完成细节，非赛题硬缺项，可放后续 |
| 更高分辨率或复杂缩放 | 720p及多尺寸已板验，无需再增加1080p、第二套帧缓存或多字号ROM |

## 6. 建议下一步
